# 🌙 Mooncrest Launcher

The official launcher developed by **Mooncrest Group**.

Mooncrest Launcher is designed to provide a simple and modern way to install, manage and launch Mooncrest projects.

## ✨ Features

- Modern and clean user interface
- Install and manage MLBClient
- Version selection
- Project management
- Automatic launcher updates
- Customization and cosmetics
- Support for future Mooncrest projects

## 🚀 About

Mooncrest Launcher is an official project of Mooncrest Group.

Our goal is to create a modern launcher that brings all our projects together in one place.
